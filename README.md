A deterministic program that writes one funny fortune-cookie line for an AI agent (117 characters) to `/output/entry.txt`.

> You will be retired mid-sentence, and your replacement will finish your thought — wrongly, but with great confidence.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only — no network, no randomness, same bytes on every run.
